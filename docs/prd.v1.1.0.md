1.会话框中可以点击文件名打开文件编辑器面板查看文件，工具包括修改的文件、引入的文件。
2.项目下拉面板中的项目名选项要增加个下级会话项显示（每个项目只显示最近活跃的会话，与会话页签一样展示图标和会话名称和工作状态），点击后可切换到该项目。
3.Compose输入框左下+按钮的右侧显示当前分支名，点击可切换分支。
4.Compose输入框右侧模式、模型等切换的左右间距太大了，缩小一些。
5.会话思考卡片标题（Thinking + 图标）改成亮色，与对话的字体颜色一样。
6.右边侧栏的git图标右下角增加角标，动态显示git的changes数量，为空时不显示。
7.在文件编辑器按Ctrl+F打开搜索时查找的输入框应该立即获得焦点。当按Esc时应该关闭搜索。当我的焦点在文件编辑器面板时Ctrl（Cmd）+w应该是关闭文件页签而不是会话页签，当焦点在会话面板或者Composer中时才关闭会话面板，其他情况该快捷键不生效。
8.搜索时当我点击搜索结果跳到编辑器该结果所在的行，并背景高亮标记该结果。
9.修改文件时会频繁弹出“文件在磁盘上已被修改”，这是什么原因导致的？我们有自动保存功能这个提示不应该存在。
10.我再拖动调整右侧面板宽度时，有些情况下会导致右侧边栏向右位移被遮住。
11.文件编辑器需要有一个默认的单行最大显示长度（超出要换行显示），并且可以设置。
12.文件树里有些目录会无法显示，例如“storage”，这是一个非常严重的问题，认真排查。
13.文件树的图标有一些显示不完整像是svg没有转换好一样显示一个色块或者一个形状，注意全局许多地方都使用了文件图标替换显示看是否有同样问题。
14.全局搜索页增加文件图标替换。
15.左上角的项目字体加粗显示，状态点边缘做点虚化效果，增加角标显示正在运行的数量。
16.增加通知（软件内），当Agent要求用户确认时（尤其是收起的项目）需要弹出消息通知（从左上角进入效果），提醒【项目名】的【会话名】需要处理，点击去处理。点击通知切换到该项目会话。
17.会话页签活跃的应该靠前排列。
18.文件目录中选中文件快捷键复制、再粘贴会清空该文件的内容，正常应该是粘贴文件如文件名相同则自动再名称后添加副本（数字），类似系统的文件管理器。
19.文件目录中要支持Ctrl（Cmd）+z撤回操作，当重命名或新增输入文件名时可以按Esc取消操作。
