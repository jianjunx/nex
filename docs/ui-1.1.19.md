# 1.1.19 工作台 UI

来源：本地 agent-ui 的 Beautiful UI，MIT 许可随组件保留。

| 组件 | Nex 位置 | 方式 |
| --- | --- | --- |
| LoadingState | 对话等待提示 | 直接组件 |
| ThinkingState | 思考内容 | 实时内容适配 |
| StreamingText | Assistant 回复 | 实时内容适配 |
| ToolChips | 工具调用卡 | 实时内容适配 |
| TaskRows | 计划步骤 | 真实状态驱动 |
| CodeBlock | Markdown 代码块 | 保留现有语法高亮 |
| ApprovalCard | 提问与选择审批 | 保留原有回调 |
| RecommendationCard | 计划审批 | 保留原有回调 |
| SelectionActions | 消息上下文菜单 | 保留原有回调 |
| ChatComposer | 对话工作区容器 | 实时内容适配 |
| PromptBar | 输入区 | 保留附件、命令、发送与停止 |
| ContextCards | 概览文件预览 | 真实打开文件 |
| DiffTable | 对话中的文件变更 | 保留差异查看行为 |
| RecordsTable | 文件树 | 保留文件操作 |
| FilterTable | 概览任务筛选 | 真实会话与选择回调 |
| Flowchart | Mermaid 图 | 保留 Mermaid 渲染 |
| InsightCards | 工作区统计 | 真实项目计数 |

| Search | 全局搜索面板 | 保留搜索逻辑 |
| FineTuneCard | 设置中的布局调节 | 受控宽度值 |

适配组件使用 `children` 接入 Nex 原有功能，不挂载上游演示状态机。
这并非将全部页面替换成上游演示：设置、Git、编辑器和终端保留功能结构，
通过统一主题令牌调整视觉；20 个组件均有对应接入点。
样式限定在 `.beautiful-ui` 内，共享主题支持深浅模式、焦点和减少动态效果。
左侧按项目分组展示会话，顶部不再显示项目选择器和会话页签。
文件、搜索、Git 与终端入口横排于顶部；右侧不再有竖排图标栏。
点击入口展开/收起工具侧栏，窄窗口使用覆盖式侧栏。
打开的文件在带焦点约束的弹窗中预览和编辑，不再占用独立分栏；
关闭弹窗仅隐藏编辑器，保留打开文件与草稿。项目管理与新建任务入口位于左侧。

## 开发预览

运行 `pnpm dev --host 127.0.0.1` 后打开 `/ui-preview.html`。
这是明确标注的示例数据预览，使用 Tauri 官方 mocks，不连接 Agent 后端，
不代表文件操作、审批执行或终端已经通过原生端到端验证。
生产构建入口仍为 `index.html`，不包含开发预览入口。

## 验证命令

`pnpm test`、`pnpm lint`、`pnpm build`。
发布前仍需在 Tauri 实机回归审批、附件、文件操作、终端和窗口尺寸变化。

## 最新交互调整

- 左侧移除工作区概览和项目管理入口；项目标题右侧的加号打开文件夹选择器。
- 项目顺序独立持久化，切换与重新打开已有项目不改变位置，新增项目追加至末尾。
- 新建任务固定选择列表第一个项目，直接创建 NexAgent 空会话。
- 智能体选择位于 Composer 分支选择之后；空会话可切换，有消息后禁用，并由数据库再次校验。
- 终端位于对话与输入区下方，独立折叠和调整高度，不再依赖文件/搜索/Git 侧栏。
- 以上新需求覆盖前文的概览组件接入位置；概览组件不再作为工作台入口。

## 会话视觉对齐

以源组件的 ChatComposer、ThinkingState、ToolChips 与 ApprovalCard 为参考：
回复使用无卡片正文，用户气泡和输入区使用中性色 field；思考使用默认折叠的
轻量标题和展开竖线；工具使用紧凑行及缩进详情；审批使用 14px 卡片、8px
选项和中性色提交按钮。真实状态不接入上游演示计时器。
思考内容在用户向上滚动阅读时停止自动贴底；计划提交显示忙碌态并禁用重复操作。

## 全项目统一风格

globals.css 是全应用唯一主题令牌来源，agent-ui.css 不再声明第二套根主题。
旧 glass-* 引用已从业务 UI 和基础组件移除；material-* 保留为语义名称，
但现在映射到不透明中性表面。设置、文件、搜索、Git、终端外壳及菜单、
弹窗共享边界、按钮、输入框、焦点和浮层规范；保留状态色与代码语法配色。
CLAUDE.md 已同步新标准，designSystem.test.ts 防止重新引入旧玻璃引用、
背景模糊与内高光。浅色和深色设置弹窗已在浏览器预览检查；原生多平台
功能验收仍需实机完成。
