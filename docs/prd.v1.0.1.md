git功能优化:
1.分支右侧的上下箭头用红色(上箭头)和绿色(下箭头)，如果本地有可推送的提交，则在右侧刷新的前面显示一个"Push”按钮，如果没有就隐藏。
2.分支下拉(本地&远程)应该按新旧程度来排序，新的放前面。
3.如果git拉取、推送、刷新等操作报错了则弹窗提示，并且可以查看改错误的git错误详情。

使用优化：
1.会话输入框、会话气泡卡片和文件编辑器当前都无法使用右键菜单，非常不便，需要增加自定义菜单。
2.会话输入框有时会发生不能通过快捷键进行复制、粘贴、剪切等等操作。
3.在MacOS上我使用Cmd+w直接关闭了软件，这是不合理的，Cmd+w应该是关闭页签（要弹起确认按钮，Windows也加相应快捷键），当没有页签时则不处理，不允许直接关闭软件。
4.当用户按了Cmd+q退出或者点了关闭时如果有任务在执行则弹窗提示并二次确认。
5.为终端添加快捷键 Ctrl+` 按快捷键后可以切换终端面板的显示隐藏。

性能优化:
1.每次打开项目，软件会有个几秒的响应时间（鼠标转圈圈，类似软件无响应那种情形）。
2.当打开的项目变多容易无响应然后强制退出，再次打开后切换项目软件直接瘫痪无响应。
