# 简介
Nex是一个Agent集成环境工具，它支持通过ACP协议来集成众多Agent开发工具（Codex、Claude Code、Cursor CLI、Opencode等），Agent功能上与zed的Agent模式相似，Agent集成使用zed的ACP协议适配，我们使用Tauri来开发，界面设计要严格按照苹果的液态玻璃设计语言。

# 主要功能：
1. 桌面端应用，跨平台。
2. ACP，软件需要像zed一样支持通过ACP将不同的Agent开发工具集成起来。
3. git，需要集成git功能，可以移植VSCode的git功能。
4. 终端，需要支持打开终端工具
5. 文件系统，本次只做文件目录预览和简单的文件弹窗查看，后期可集成文件编辑器功能。
6. 多项目管理和多回话，系统支持打开多个项目，左上角可切换项目，项目可创建多个Agent对话，并且支持多个Agent同时执行任务，切换项目和切换对话需要保持Agent任务继续执行。
