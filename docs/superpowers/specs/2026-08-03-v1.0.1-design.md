# v1.0.1 迭代设计摘记

日期：2026-08-03  
来源：[`docs/prd.v1.0.1.md`](../../prd.v1.0.1.md)

## 范围

本迭代覆盖 PRD 三块：Git 面板增强、使用/快捷键优化、打开与切换项目性能。

## 决策摘要

| 主题 | 决策 |
|------|------|
| Ahead/behind 箭头 | `↑` 用 `--error`，`↓` 用 `--success`；`ahead>0` 时刷新前显示 Push |
| 分支排序 | 后端 `BranchInfo.tipTime`（tip commit 时间），本地/远程各自降序 |
| Git 错误 | `GitErrorDialog` 弹窗 + 可展开完整 stderr；网络层保留全文 |
| 右键菜单 | 输入框 `TextEditContextMenu`；编辑器 `EditorContextMenu`；气泡沿用 `MessageContextMenu` |
| 输入框剪贴板 | `files.copy/cut/paste` 的 `when` 排除 `input/textarea` |
| Cmd/Ctrl+W | `workbench.closeActiveTab` → 关对话页签（有确认）；无页签 noop；不关窗 |
| 退出确认 | `onCloseRequested`：有 running/waiting/starting 任务时二次确认 |
| Ctrl+\` | `KeyCombo.ctrl` 物理 Ctrl；`terminal.toggle` 全平台 Ctrl+\`（非 Mac Cmd） |
| 性能 | active-first 分批 hydrate + generation 取消；watcher 仅 active；重 IPC `spawn_blocking` |

## 非目标

- 编辑器页签不绑 Cmd+W
- Thinking/ToolCall 气泡右键（本迭代可不做）
- Agent 进程不因切换项目批量 kill
